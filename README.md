# Wander Vietnam — CSS Assignment

An original three-page travel guide built for the CSS course assignment.

## Files

- `index.html` — Destinations page (contains six destination images)
- `journeys.html` — Curated travel ideas
- `culture.html` — Culture, food, heritage, and craft
- `style.css` — The single shared stylesheet used by all three pages

## Run locally

Keep the four files in the same folder and open `index.html` in a browser. The images use remote Unsplash image URLs, so an internet connection is needed to load them.

## Requirements demonstrated

- A “Skip to main content” link positioned off-screen until `:focus`.
- Semantic header, navigation, main, section, article, figure, and footer elements.
- Three navigation links styled with multiple CSS properties and `aria-current` for the active page.
- CSS Grid for the destination, journey, and culture card layouts.
- Flexbox for the navigation, header, footer, and several content rows.
- Image box model: border, padding, and border-radius.
- Hover transitions on navigation, cards, images, buttons, and text links.
- `:nth-child()` selectors to vary card-image shape.
- Responsive breakpoints and a `prefers-reduced-motion` accessibility preference.
- Visible keyboard-focus indicators and descriptive alternative text for meaningful images.

## Before submitting

1. Open every page and confirm that images load and all navigation links work.
2. Validate each HTML file at <https://validator.w3.org/>.
3. Deploy the folder with GitHub Pages (or another static host).
4. Run the published URL through <https://wave.webaim.org/> and fix any reported errors, especially contrast errors.
5. Submit the published website URL, not the repository URL alone.

## Image note

Photographs are loaded from Unsplash image CDN URLs. Check the corresponding image source and its current license/credit information before publishing for a public or commercial purpose.
